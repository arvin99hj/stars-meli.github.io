REFLECTIONS — CONSTELLATION WEBSITE

START
1. Extract the ZIP file.
2. Keep the assets folder beside index.html.
3. Open index.html in a modern browser.
4. Press play. The supplied MP3 is already connected.

TIMING WORDS
1. Click TIMING EDITOR.
2. Play the song and pause at the start of a sung word.
3. Enter the word and click ADD WORD AT CURRENT TIME.
4. Tick "Highlight this word" for the special bright star (for example, the word "eyes").
5. Adjust timestamps directly in the list.
6. Timings save automatically in this browser.

EXPORT / IMPORT
Use EXPORT TIMINGS JSON to back up your word timings. Import that JSON later from the editor.

NOTES
- No song lyrics are preloaded. Add the words and timestamps you want to display.
- The special glow is controlled per word with the Highlight checkbox.
- For best local-file compatibility, keep the MP3 at assets/reflections.mp3.
- Google Fonts require an internet connection; the page still works with fallback fonts offline.
